Firewall bloqueando conexiones

El firewall de Windows está impidiendo que los celulares se conecten al sistema. El puerto 8443 no es accesible desde la red.

Para solucionarlo:

  1. Abra Panel de Control → Firewall de Windows
  2. Clic en Permitir una aplicación a través del firewall
  3. Busque Java o OpenJDK y marque las casillas de red Privada
  4. Si no aparece, clic en Permitir otra aplicación y agregue javaw.exe
  5. Reinicie el sistema ERP

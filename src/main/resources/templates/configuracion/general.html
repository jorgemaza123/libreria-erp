Seguridad de Datos

Copia de Seguridad

Descargue una copia completa de su base de datos en formato SQL. Este archivo contiene toda la información del sistema: productos, ventas, clientes, configuraciones, etc.

Recomendación: Realice copias de seguridad periódicas (diarias o semanales) y guárdelas en un lugar seguro fuera del servidor.

Instrucciones de Restauración

Para restaurar un backup descargado:

  1. Detenga el sistema ERP
  2. Abra una terminal o línea de comandos
  3. Ejecute el comando: 
    psql -U postgres -d libreria_db -f backup_FECHA.sql
  4. Reinicie el sistema ERP
Importante: La restauración sobrescribirá todos los datos actuales. Asegúrese de tener un backup reciente antes de restaurar.
